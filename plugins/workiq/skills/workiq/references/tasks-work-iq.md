# Planner route index

Read the selected contract before the first relevant call. Actions also require
the mutation contract; read-only plan discovery does not authorize a task change.

## Routes

| Route | Intent | Read |
| --- | --- | --- |
| planner-read | Resolve/list plans and tasks | [Planner](tasks-contract-work-iq.md) |
| planner-actions | Create/change/complete/delete tasks | [Actions](tasks-actions-work-iq.md) |
